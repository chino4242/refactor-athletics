# Viking Theme — Enemy Sprite Prompts

## Instructions
- Generate via Gemini API: `gemini-2.5-flash-image`
- Append to every prompt: `Use a solid bright green (#00FF00) background. Do NOT use transparency or checkerboard.`
- Post-process: remove green pixels + resize to 64×64
- Save as: `public/enemies/viking/{exercise_id}_t{tier}.png`
- Color palette: ice-blue + frost-white + dark iron (Viking theme)
