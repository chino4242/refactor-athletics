# Samurai Theme — Enemy Sprite Prompts for Gemini

## Instructions
- Generate each as a **64×64 pixel art** image
- Use **transparent background** (PNG with alpha)
- Style: SNES RPG bestiary, hard pixel edges, no antialiasing, no smooth gradients
- Color palette: Indigo/deep purple tones with cherry blossom pink accents (Samurai theme)
- Each creature should face LEFT (toward the player position)
- Save files as: `public/enemies/samurai/{exercise_id}_t{tier}.png`
  - tier 0 = small, tier 1 = medium, tier 2 = boss
